# 四角色完整面部网格

夏夏、沈露白、谷雨、贝拉均保留现有 `portrait-frame.png`，新增同目录的 `face-rig.json`。它是本项目渲染器使用的 2.5D 面部模型，适用于现有固定机位；不是 Cubism 工程、moc3 或可任意转头的 GLB 模型。

## 结构与接入

| 角色 | 数据目录 | 顶点 | 三角面 |
| --- | --- | ---: | ---: |
| 夏夏 | `data/models/eciyuan-xiaxia/` | 487 | 956 |
| 沈露白 | `data/models/eciyuan-lubai/` | 511 | 1004 |
| 谷雨 | `data/models/eciyuan-guyu/` | 509 | 1000 |
| 贝拉 | `data/models/eciyuan-beila/` | 507 | 996 |

每个模型包含 15 个命名部位：皮肤、下颌、脸颊、左右眉、上下唇、左右眼睑、左右眼球、口腔、上下牙齿、舌头。10 个驱动参数控制开口、圆唇、嘴角、左右眉、左右闭眼、水平/垂直视线及舌头高度；这些部位并非全部具有独立动画轨道。

连续网格将口唇和眼睑位移传递到周围皮肤，避免原来局部矩形贴片边界。眼睑遮住眼球；牙齿和舌头在唇部边界内绘制。中性时保留原始纹理，口腔内部为补建近似形状。大幅侧转、真实肌肉仿真和音素识别不在当前模型能力内。

模型由 `avatar/prototype` 接口读取并校验，随后在角色预览和独立播出窗口共用的渲染器中自动加载。存在完整模型时关闭旧眼嘴贴片，继续使用原有头部、饰品及透明度遮罩。重新加载插件并打开播出窗口即可使用，不需要安装 OBS 或新增运行时依赖。

## 重新制作与预览

在已有四个角色原图的开发仓库中运行：

```sh
pnpm avatar:build
pnpm avatar:verify
pnpm avatar:preview
```

制作需要 macOS 自带 Vision、Xcode 命令行工具和已安装的 Chrome，使用项目已有的 playwright-core 与 Pixi；普通使用不需要运行制作命令。可通过 `DAFEIYU_TEST_CHROME` 指定 Chrome。四个模型全部通过形变检查后才开始写入。原图与模型通过 SHA256 绑定，换图后必须重新制作。

交互预览生成到 `artifacts/face-rigs/index.html`，也可直接给预览脚本传入输出目录。预览内嵌原图、模型和现有角色参考录音，可检查开口、圆唇、微笑、闭眼和连续变化；录音取自 `data/role-voices/references/`。页面不连接直播间。模型及原图在本机数据目录中，不纳入 Git，也不会自动包含在 npm 安装包中；分发时须连同现有角色素材一起复制。

## 验证结果与边界

- 四个模型分别检查 512 组含横展的极限参数组合，未发现三角面翻折。此检查不能证明任意参数组合或所有中间帧都绝无失真。
- 浏览器中性纹理比较：沈露白、谷雨、贝拉逐像素一致；夏夏最大单通道差值为 1，平均差值约 0.0000205。该结果证明纹理保持，不代表表情误差小于 1 像素。
- 实际浏览器检查了四人的张口、圆唇、微笑和闭眼，页面错误为 0。完整播出检查另外覆盖真实模型加载、角色切换、状态推送、紧急停止和断连安全画面。
- 未完成直播伴侣最终音画误差、SyncNet、LMD 或主观自然度验收。当前使用播放音频的频带能量估计开合和唇宽，尚无音素时间戳。

随插件分发的 Pixi 7 使用动态函数生成着色器参数绑定，独立播出页因此允许本地脚本的 `unsafe-eval`；仍仅从本机鉴权服务加载脚本，不放开远程脚本来源。
