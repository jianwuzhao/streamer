## 大肥鱼 0.20.0 / DaFeiYu 0.20.0

- 完善中英文说明、赞助入口与 GitHub Issues 需求墙。
- 新增设置页 JSON 配置导入导出，包含摘要预览、确认覆盖、严格校验和事务回滚。
- 备份不包含 API Key、环境变量、观众/对话/训练数据、模型或个人角色素材。
- 导入前请下播并退出预览；导入后重新确认授权、登录和数据用途，并在启用云端前测试连接。

- Updated Chinese and English guides, sponsorship links and the GitHub Issues feature wall.
- Added JSON settings export/import with preview, explicit replacement, strict validation and transactional rollback.
- Backups exclude API keys, environment variables, runtime data, models and personal character assets.
- Stop live/preview before importing. Reconfirm rights, login and data use, and test cloud connectivity before enabling it.

安装 / Install: use the attached `.tgz` in your DSH plugin manager. Declared compatibility: DSH `0.2.2-rc.1`, Node ≥22.13.0. The macOS native output window requires macOS 13+. Other host versions and Windows/Linux broadcast workflows require separate verification.
